# 재점검 및 검증 기록

검증일: 2026-09-29. 환경: macOS Apple Silicon, Python 3.13.3. 실제 API 키·실계좌 주문·입출금 없이 실행했습니다.

## 주요 수정

- 기존 주문만 검사하던 노출 로직을 후보 주문 포함 사전 검사로 변경.
- 자산 손실 후에도 초기 자본으로 한도를 계산하던 문제 수정.
- 동시 UI 요청·엔진 틱 직렬화, DB 프로세스 잠금, 일시정지 시 남은 매수 주문 취소.
- 재시작마다 재사용되던 paper 주문·체결 ID를 UUID로 변경.
- 보호 close-all 수량이 최초 등록 수량에 고정되던 문제 수정.
- 익절 제출 실패 전에 체결을 처리 완료로 표시하던 문제 수정.
- 모의 체결의 주문·포지션·수수료 기록을 원자적으로 저장.
- 손절·정리 후 실제 잔여 수량 확인, 보호 실패 시 미체결 진입 취소와 시장가 정리.
- 5.9배가 정수 변환으로 5배가 되던 입력 허점, NaN/Infinity, 음수 한도·손절, 비용 미달 그리드 거부.
- 최초 상태 조회가 모의 시세·체결을 진행하던 부작용 제거.
- HTTP 정적 파일 경로 이탈, CSRF·Host·Origin 처리, 포트 충돌 전 엔진 시작 문제 수정.
- 최신 Binance Algo 손절 경로와 주문 메타데이터 보존·응답 유실·펀딩 기록 보강.

## 자동 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

49개 테스트. 위험 검사·주문 사이 즉시 체결·부분 체결·주문 응답 유실·영속 정지·자정 경계·원자적 저장·재개 중 보호 실패·실계좌 차단·설정 영속성·HTTP 보안·QuantStats 자본 유출입 보정 등을 검증합니다. HTTP 테스트는 loopback 포트 바인딩 권한이 필요합니다. 기본 Python에 QuantStats가 없으면 해당 테스트만 skip되며 가상환경에서는 실제 실행했습니다.

```bash
.venv/bin/python scripts/verify_ui.py
```

Chromium 실제 브라우저에서 1440px 데스크톱, 390px·360px 모바일의 세 화면을 검증했습니다. 설정 저장·새로고침 유지, 잘못된 범위 오류, 시작·중단·정리, 정리 취소 모달, 3개 시나리오 실행, 가로 넘침 없음, 버튼 텍스트 넘침 없음, JavaScript 오류 없음, 가격 캔버스 비어 있지 않음을 확인했습니다. 결과 이미지는 `artifacts/*desktop.png`, `artifacts/*390.png`, `artifacts/*360.png`입니다.

## 합성 시나리오


기본 400 USDT 모의 배정 자본의 고정 검증 결과입니다. 각 시나리오 96개 합성 가격, 매매 수수료·시장가 슬리피지·변동 시각과 요율의 합성 펀딩 정산을 반영합니다.

## 실행 환경

- 실제 로컬 HTTP 서버 `/`, `/api/status`, GUI 제어 경로 실행.
- 키 없는 testnet 시작은 오류 코드 2와 명확한 안내로 종료.
- 패키지 wheel 빌드 및 HTML/CSS/JS·Lucide 파일 포함 확인.
- Docker 명령은 존재하지만 daemon 소켓이 없어 Hummingbot 컨테이너 실행은 미검증.
- `requirements.lock`은 이 환경에서 설치한 분석 의존성을 고정. Linux·다른 Python 버전은 별도 실행 검증하지 않음.

## 남은 사항

Hummingbot V2 런타임·커넥터 재사용, 실제 테스트넷 주문·손절·자동 취소, 한국 거주 계정의 선물/API 권한, 계정별 담보·수수료·청산 규칙, 시장 데이터 기반 검증은 미완료입니다. GS Quant는 검토만 했고 설치·사용하지 않았습니다. 로컬 시뮬레이션과 mock 테스트를 실거래 인증으로 간주하지 않습니다.
